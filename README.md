# Pro Gen Plumbing — Website

Live address: **https://progenplumbing.com** (hosted on Vercel)

Static site — plain HTML / CSS / JS. No build step is needed to host it; `build.py` is only for editing.

## Folder

```
index.html                 Home
services.html              Services hub
services/*.html            6 service detail pages
about.html                 About Matthew
contact.html               Contact + form + map
service-areas.html         GTA coverage
work.html                  Our Work — project photos + Instagram reels
404.html                   "Page not found" page (Vercel shows it for any bad link)
sitemap.xml, robots.txt    For Google — generated by build.py
vercel.json                Vercel settings: short URLs (/contact, /about…), caching, security headers — generated by build.py
.vercelignore              Keeps build.py / README / zips off the live site
favicon.ico                Browser tab icon
css/style.css              All styles — brand colours live in :root at the top
js/main.js                 Header, mobile menu, FAQ, slider, form sending, Instagram loader
assets/                    Job photos (job-*.jpg), logos, icons, og-image.jpg (the preview shown when the link is texted/shared)
build.py                   Generator — edit content in one place and regenerate every page
make-preview.py            Optional: bundles the whole site into one file for previewing
```

## Editing content

Edit the `CONTENT` block at the top of `build.py` (business info, services, reviews, FAQs, areas, photos), then run:

```
python3 build.py
```

Every page, the sitemap and vercel.json are regenerated with the shared header/footer, so nothing drifts out of sync.
Don't hand-edit the .html files — the next `build.py` run overwrites them.

## Adding photos

All job photos are listed once, in the `PHOTOS` block near the top of `build.py` (file name, description for Google/screen readers, caption, and a `focus` point that decides what stays visible when a box crops the photo).

1. Put the photo in `assets/` as a portrait JPG about 1050×1400, under ~200 KB, named like `job-what-it-shows.jpg`. Strip location data from phone photos before uploading.
2. Add an entry to `PHOTOS` in `build.py`, then use its key in:
   - `WORK_PHOTOS` → the Our Work gallery (shown 3 across, best first)
   - `HOME_WORK_PHOTOS` → the two photos beside the Instagram reels on the home page
   - `SERVICE_PHOTO` → the photo on each service page
3. Run `python3 build.py`.

Where the current 6 photos appear: home hero (`job-hero-ensuite.jpg`, a landscape crop of the ensuite), home "Why Pro Gen" capsules (onyx + green showers), home FAQ (tub ensuite), home work strip (curbless + in-progress), About page (ensuite, in-progress, curbless, onyx), Our Work (all six), and one per service page.

Matthew's portrait: the About page "Meet Matthew" spot currently shows the ensuite photo. When you have a headshot, add it to `PHOTOS` (e.g. key `"matthew"`) and change `pimg("ensuite", "photo--tall reveal reveal--right")` in `page_about()` to `pimg("matthew", …)`.

## Deploying on Vercel

1. vercel.com → Add New → Project → import this `progen` folder (via GitHub, or drag-and-drop with the Vercel CLI: `npx vercel` inside the folder).
2. Framework preset: **Other**. Build command: *(leave empty)*. Output directory: **`.`** (the folder itself).
3. Project → Settings → Domains → add `progenplumbing.com` **and** `www.progenplumbing.com`; set **www to redirect to progenplumbing.com** (the site's canonical URLs use the non-www address).
4. At your domain registrar, add the DNS records Vercel shows you (usually an `A` record for the root and a `CNAME` for www). HTTPS is automatic.
5. After it's live: Google Search Console → add `progenplumbing.com` → submit `https://progenplumbing.com/sitemap.xml`.

To update the site later: run `python3 build.py`, then redeploy (push to GitHub, or `npx vercel --prod`).

## Before going live — checklist

1. **Contact form — connected.** Requests go to Formspree (form `mbgleejo`, project "ProGen Plumbing"): each one is emailed to the address set in that form's settings and listed on the form's Submissions page (kept 30 days on the free plan, 50 requests/month). Visitors see a "Thanks — we'll call you back" message on the page. The first real submission triggers a confirmation email from Formspree — click it once to activate. Once the site is live, set Formspree → project Settings → Restrict to Domain → `progenplumbing.com`.
2. **Google Business Profile.**
   - Add the website (`https://progenplumbing.com`) — the profile currently says "Add website". This is the single biggest local-SEO step.
   - Business Profile → "Ask for reviews" → copy the short review link into `BIZ["google_review"]` so "Leave a Google review" opens the review box directly.
   - Update `BIZ["review_count"]` as reviews grow (37 as of Oct 1, 2026).
3. **Hours mismatch.** Google says "Open 24 hours"; the site says "Mon–Sun · By appointment, same-day & evening availability". Pick one and make both match (`BIZ["hours_short"]` in build.py, and the Google profile).
4. **About page.** Replace the italic "Owner bio placeholder" paragraph with Matthew's own words, and add his portrait.
5. **Licensing claims.** The site says "professional plumbing", not "licensed". Only add a licence number/wording once confirmed.
6. **Email.** Optional: set up `info@progenplumbing.com` (Vercel doesn't do email — use Google Workspace, Zoho or your registrar's email forwarding) and swap it into `BIZ["email"]`.
7. **Instagram reels.** Reel 1 is a collab post owned by @sebstonecountertops — if they delete it, the card falls back to a "Watch on Instagram" link. Add/replace reels in `REELS` in build.py.

## SEO & tech notes

- Every page has a canonical URL, Open Graph/Twitter tags with an absolute preview image, and JSON-LD (`Plumber` + `WebSite` on home, `BreadcrumbList` on inner pages, `Service` on service pages).
- The schema deliberately has **no star rating** (Google doesn't allow a business to mark up its own reviews) and **no opening hours** (Google uses the Business Profile).
- CSS/JS are linked with `?v=<hash>` so visitors always get the latest version after an update, while Vercel caches them for a year.
- Instagram's embed script only loads when the reels scroll into view (keeps the homepage fast).

## Brand tokens

Defined in `css/style.css` `:root`. Pulled from the logo:

| Token | Value | Use |
|---|---|---|
| `--ink` | `#070A0E` | Footer, deepest backgrounds |
| `--charcoal` | `#0F151C` | Headings, dark blocks |
| `--steel` | `#2E4B65` | Secondary steel-blue (logo splash) |
| `--accent` | `#1A6FD0` | Buttons, links (AA contrast on white) |
| `--accent-hi` | `#4DA3FF` | Icons/text on dark |
| `--silver` | `#C9CED4` | Muted text on dark (logo metal) |
| `--bg-alt` | `#F2F4F7` | Alternating section background |

Fonts: Inter (headings) + DM Sans (body) via Google Fonts.

Logo files: `logo-dark.png` / `logo-light.png` are the full-size masters. The site uses the small optimised copies `logo-56/112/168.png`, `logo-512.png` (Google), `apple-touch-icon.png`, `favicon-96.png` and `favicon.ico`.
